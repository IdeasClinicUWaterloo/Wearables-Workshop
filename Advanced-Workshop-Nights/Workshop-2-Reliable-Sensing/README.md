# Workshop 2: Reliable Sensing 
Welcome to the Reliable Sensing Workshop!

In this workshop you will learn how to effectively place a sensor on a wearable and determine how to get reliable information despite movement varying conditions and users. 

## Outcomes
By the end of this workshop you should be able to: 
- Integrate sensors into wearables
- Obtain reliable sensor readings and verify accuracy 
- Distinguish sensor failures from fit failures
- Ensure sensor integration is durable and reliable
- Having sensor readings be accurate with different users and scenarios 

## Materials 
- Sensor (pulse oximeter, accelometer, ultrasonic sensor)
- Wires
- Arduino Uno
- Wearable (from previous workshop)
