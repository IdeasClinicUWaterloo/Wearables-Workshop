# Workshop Stations
The Wearable Workshop is divided into two stations that introduce participants to the core skills required for wearable prototyping. Each station includes a guided tutorial, a sample project, and support from workshop supervisors.

By completing both stations, student will gain experience in soft fabrication through sewing and EVA foam before applying these skills in combination to electronics and mechanical design to an independent project.

---
## Station 1 - Sewing
This station will be comprised of multiple smaller sub-stations that will allow you to create a fabric glasses case. These stations include an ironing station, fabric cutting station, sewing station, and a hand sewing station. Read the instructions for this station [here](Sewing-Tutorial/README.md).

## Station 2 – EVA Foam
In this station, you will create a lightweight EVA foam glasses case with an adjustable hanging strap that can be attached to a backpack or bag. Read the instructions for this station [here](EVA-Foam-Tutorial/README.md).
